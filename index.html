Ashley Life Observatory (ALO)

ALO Drive Sync

ALO Drive Sync is a personal-use integration being developed to help the operator organize and synchronize authorized ALO project files between Google Drive and private project storage.

What it does

When configured and authorized, the integration is intended to create, read, and update only Google Drive files used with the app, alongside separately configured private ALO project storage. Availability and successful synchronization are not guaranteed while setup and validation are in progress.

Access and control

Google access is requested through OAuth consent. The operator can revoke access through Google Account settings. The integration is not a general-purpose public file-sharing service.

Read the Privacy Policy for details about intended access, storage, and deletion.

ALO Drive Sync is an independent personal project and is not affiliated with Google.
